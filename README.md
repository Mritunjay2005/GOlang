🛠️ Setup (Start Coding in 5 Minutes)
1. Install Go
Go to: https://go.dev/dl/
Download and install for your OS
Verify installation:
go version
2. Install VS Code
Download: https://code.visualstudio.com/
3. Install Go Extension
Open VS Code
Go to Extensions (Ctrl + Shift + X)
Search: Go (by Go Team at Google)
Install it
4. Run Your First File
go run main.go
